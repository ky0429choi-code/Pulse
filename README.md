# Pulse Dashboard (Operational Console)

## ⚠️ SECURITY WARNING: HIGHLY SENSITIVE
This repository contains the interface and orchestration logic for operational data management. **ABSOLUTE SECURITY** must be maintained at all times.

### 🚫 STRICT PROHIBITIONS
1.  **NO OPERATIONAL DATA ON GITHUB:** Never upload `.xlsx`, `.csv`, `.json`, or `.txt` files containing actual site data, headcount figures, or cost matrices.
2.  **NO IP EXPOSURE:** Recipes, internal support algorithms, and specific corporate identifiers must be generalized or tokenized before any commit.
3.  **SESSION LOGGING:** All application access and data movements are tracked via session-based security logs.

### 🛠️ Core Modules
- **Worklog (업무 일지):** Operational logging linked with Google Calendar.
- **Reporting (보고서):** Automated operational report generation.
- **Calculator (인당량):** Resource efficiency analysis.

### 🔐 Security Compliance
This project adheres to strict data masking and anonymization protocols. For details, see [SECURITY.md](./SECURITY.md).
