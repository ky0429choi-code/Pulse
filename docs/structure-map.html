Pulse 구조도

GitHub Pages, Google Apps Script, Google Sheets만 사용하는 무과금 운영 구조입니다.

Absolute Free Operations

요청 흐름

사용자 브라우저 로그인, 지점/날짜 선택, 대시보드 확인
↓
docs/index.html + app.js 화면 부팅, 세션 복구, 탭별 모듈 렌더링
↓
services/api.js GAS Web App 호출, 세션 토큰 첨부, 인증 오류 처리
↓
gas/Main.gs → Router.gs GET/POST 진입, action whitelist, 세션/Admin 권한 게이트
↓
gas/services/*.gs 로그인, 현황, 템플릿, 점검, 메모 업무 로직
↓
gas/repositories/*.gs → Google Sheets 시트 읽기/쓰기, 헤더 매핑, 운영 데이터 저장

폴더 역할

docs/

사용자가 보는 정적 웹앱입니다. GitHub Pages로 배포합니다.

gas/

Google Apps Script 백엔드입니다. 인증, API, 시트 처리를 담당합니다.

shared/

프론트와 백엔드가 같이 지켜야 할 API 계약을 둡니다.

specs/

구조, 배포, 운영 확인용 문서를 둡니다.

레이어별 책임

Frontend
  • 화면 렌더링
  • 탭 전환
  • 세션 저장/복구
  • 복사, 메모 입력, 점검 실행 버튼
API Gate
  • action whitelist
  • GET/POST method check
  • Public/Session/Admin 분기
  • 공통 응답 envelope
Services
  • 현황 KPI 계산
  • 템플릿 렌더링
  • 점검 결과 생성
  • 메모와 로그 처리
Sheets
  • 인원운영
  • 업무메모로그
  • 점검데이터결과
  • 권한관리, 세션, 로그

운영 원칙

무과금 고정 유료 DB, 유료 인증, 유료 호스팅을 전제로 설계하지 않습니다.
가벼운 구조 빌드 시스템이나 프레임워크를 추가하지 않고 정적 파일 중심으로 유지합니다.
계약 우선 API 변경 시 Router와 shared/api-contract.md를 함께 맞춥니다.
시트 보호 시트 헤더 변경은 Schema와 field map 기준으로 흡수합니다.
텍스트 안전 시트/API에서 온 텍스트는 화면 삽입 전 escape합니다.
운영 확인 배포 후 deployment checklist와 smoke check로 확인합니다.
